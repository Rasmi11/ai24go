# AI24GO — Intelligent Digital Systems

موقع شركة **AI24GO** من هولندا — أنظمة رقمية ذكية (ذكاء اصطناعي، أتمتة، مواقع، منتجات رقمية) بواجهة ثلاثية اللغات: **العربية / English / Nederlands**.

> موقع «من الصفحة الواحدة» فاخر عصري يقدّم هوية تقنية تجارية واضحة، دون أرقام مزيفة أو إدعاءات غير مدعومة.

## المميزات

- **ثلاثي اللغات (AR/EN/NL)** — مبدّل لغة فوري مع الحفظ محلياً في المتصفح (localStorage) ودعم كامل لاتجاهي RTL / LTR.
- **هوية متماسكة** — رسالتان تسويقيتان موحّدتان في كل الأقسام، اتّساق كامل في الـ CTA والـ UX عبر اللغات.
- **عرض بيانات تفاعلي** — رسوم متحرّكة بأسلوب «MiniSystem» لكل خدمة (المدخلات ← المعالجة ← المخرجات) تُبنى عند التمرير وتتوهّج عند التحويم.
- **خلفيات حيّة** — مشهد هيرو مضمّن ومركزي حول «كرة ذكاء» متحرّكة (منفصلة بصرياً ورسمياً في العربية عن محتوى النص)، مع دعم إيقاف خارج الشاشة.
- **أمان للحركة** — احترام `prefers-reduced-motion` وتعطيل كامل للحركة عند الطلب.
- **جاهزية للجوال والتجاوب** — تخطيطات مرنة عبر أحجام الشاشات (1024px / 768px / 480px).
- **لا إضافات زائفة** — بلا إحصاءات/توصيات/شعارات عملاء/رسائل وهمية؛ أقسام «أعمالنا» تُظهر قالب حالة دراسية صريح.

## الأقسام

1. **Hero** — الرئيسية: رسالتان، زران (ابدأ مشروعك / اكتشف خدماتنا)، و3 حقائق (مقرّنا في هولندا · نخدم أوروبا والعالم العربي · من الفكرة حتى الإطلاق).
2. **Marquee** — شريط قُدرات متحرّك.
3. **الخدمات** — 4 خدم: AI، أتمتة، ويب، منتجات؛ مع خطوط النتائج و«ابدأ مشروعاً».
4. **لماذا نحن** — 4 مبادئ بسيطة.
5. **المنهجية** — مراحل العمل.
6. **أعمالنا** — قالب حالة دراسية صريح (بدون نتائج زائفة).
7. **من نحن** — نبذة مع وسم «مختبر ابتكار رقمي من هولندا».
8. **التواصل** — CTA ونموذج اتصال (mailto: info@ai24go.com) واعي باللغة.
9. **الفوتر** — روابط ووصف وأتمتة السنة.

## التقنيات

- **HTML5/CSS3** — تخطيط شبكي، خصائص منطقية (Logical Properties) لتماثل RTL/LTR، متغيّرات CSS للألوان والأنماط.
- **JavaScript (Vanilla)** — نظام الترجمة الكامل (i18n)، إدارة اللغة، رسوم Canvas (HeroScene / AboutScene / MiniSystem)، ملاحظات IntersectionObserver.
- **الخطوط:** Noto Kufi Arabic · Space Grotesk
- **الألوان:** أسود عميق `#07090c` · أخضر صنوبري `#16b988` · تركوازي `#2fe0b5` · ذهبي ناعم

## الملفات

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
python -m http.server 8080
# ثم افتح http://localhost:8080
```
